# Evidencias pendientes de captura manual

Ejecutar `flutter run -d chrome` manualmente desde el proyecto. No hay capturas generadas por el agente.

1. Selección de perfil: los tres avatares y el diálogo Administrar perfiles.
2. Inicio: promoción, botones y los cuatro carruseles (desplazar horizontal y verticalmente).
3. Catálogo: búsqueda por título, búsqueda por género, filtros Series/Películas, limpieza y búsqueda sin resultados.
4. Detalle: título seleccionado, metadatos, sinopsis, favoritos y diálogo Reproducción de demostración.
5. Mi Netflix: perfil activo, favorito agregado, eliminación y estado vacío; diálogos de cuenta/configuración.
6. Cambio de perfil: agregar un favorito con Naomi, cambiar a Alex, verificar lista separada y volver a Naomi.
7. Adaptabilidad: capturar una ventana móvil y una de escritorio; comprobar que se puede acceder a todos los botones.
8. Recursos: desconectar Internet y volver a cargar una imagen para comprobar el respaldo local.

Guardar las imágenes reales aquí con nombres descriptivos. Adjuntar también los resultados de análisis, pruebas y compilación si el informe lo requiere. No incluir datos personales ni credenciales.
